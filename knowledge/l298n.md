# L298N Dual H-Bridge Motor Driver Module Guide

## Summary
The L298N is a classic BJT-based dual H-Bridge driver. Because it uses bipolar transistors rather than MOSFETs, it has an internal voltage drop of approximately 1.8V to 2.5V, dissipating significant heat under load.

## Key Terminals & Jumper Configuration
- **12V Terminal**: Motor power input (7V to 35V DC).
- **5V Terminal**: Onboard 5V regulator output (if 5V enable jumper is ON) OR 5V logic input (if jumper is OFF).
- **5V Enable Jumper**: Keep ON if motor input is 7V - 12V to power onboard logic. Remove jumper if motor supply exceeds 12V to avoid overheating the onboard 78M05 regulator.
- **ENA / ENB Jumpers**: PWM speed control pins. Remove jumper caps to feed PWM signals from microcontroller GPIOs.

## Common Failures
- Motor doesn't spin: ENA or ENB jumper missing without PWM signal connected.
- Board overheats: Running higher than 12V with onboard 5V enable jumper shorted.
- Arduino restarts: Missing common ground between Arduino GND and L298N GND terminal.
